# LimaSat25
LimaSat was the Escola Secundaria Lima-de-Faria CanSat Portugal 2025 team.
We were selected to the final of the competition where our missions were to colect temperture, pressure and UV ray intensity data, during the CanSat's decent and to transmit that data using an APC220. 
This repository contains the Arduino and Python code used to collect, process, and store sensor data for our CanSat project.
